# Piano

Play piano in your browser with keyboard and touch support

**Live:** https://piano.freeappstore.online

A free app on [FreeAppStore](https://freeappstore.online). App id: `piano`.

## Develop

```bash
pnpm install
pnpm dev
pnpm build
pnpm run typecheck
pnpm test
```

Before publishing, run `fas check` (`npm i -g @freeappstore/cli`). Pushing to `main` deploys the app.
